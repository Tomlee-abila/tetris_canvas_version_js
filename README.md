# 🎮 Tetris DOM Game

A simple implementation of the classic **Tetris** game using pure HTML, CSS, and JavaScript. This game is playable in the browser and supports keyboard controls, lives, scoring, and a pause/restart system.

## 📁 Project Structure

```text
.
├── index.html     # Main HTML file
├── style.css      # Stylesheet 
├── script.js      # Game logic in JavaScript
```

## 🚀 How to Run

1. Clone or download this repository.
2. Open `index.html` in your browser.
3. Play and enjoy!

## 🎮 Controls

- **← / →**: Move tetromino left or right  
- **↓**: Drop faster  
- **↑**: Rotate  
- **P**: Pause the game  
- **R**: Restart the game  

## 🧠 Features

- Interactive grid-based Tetris logic  
- Live scoring and timer display  
- 3 lives with heart icons  
- Upcoming piece preview  
- Pause and resume popup  
- Game over popup with restart option  

## 🛠 Built With

- HTML5  
- CSS3  
- JavaScript (DOM manipulation, keyboard input handling)
